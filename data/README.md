# Data

Large and source datasets are not stored in this repository.

Expected local inputs include:

- Sentinel-1 GRD products downloaded from Copernicus Data Space Ecosystem.
- Sentinel-1-derived sample CSV containing `plot_id`, `Class`, `VV`, and `VH` (or `BAND_1`, `BAND_2`).
- Annual CMF-restricted binary GeoTIFFs for 2015–2025 for hotspot evolution.

Keep credentials, raw `.SAFE` directories, Sentinel-1 ZIP files, and large raster collections outside Git history.
