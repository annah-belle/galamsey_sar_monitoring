# Results

This folder documents the principal results from the Sentinel-1 SAR-based galamsey monitoring research project.

- [`model_performance.md`](model_performance.md) — classifier performance and spatial generalisation
- [`threshold_analysis.md`](threshold_analysis.md) — probability threshold evaluation and the 0.70 monitoring threshold
- [`feature_importance.md`](feature_importance.md) — contribution of Sentinel-1-derived predictors

Temporal monitoring and hotspot-evolution results are presented in the main [`README.md`](../README.md), together with the associated figures.
