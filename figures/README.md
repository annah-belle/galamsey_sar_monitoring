# Project Figures

These figures are portfolio visuals derived from the corresponding MSc thesis
analysis. They are provided to make the project's spatial, remote-sensing,
machine-learning, and temporal-analysis outputs easy to inspect on GitHub.

| Figure | Description |
|---|---|
| `study_area.png` | Study-area map showing the Southern Ghana focus area. |
| `reference_plots.png` | Reference plots used for labelling and spatial model validation. |
| `preprocessing_workflow.png` | Sentinel-1 preprocessing workflow used to generate analysis-ready SAR data. |
| `workflow.png` | Overall project workflow from Sentinel-1 data preparation through modelling and monitoring. |
| `cmf.png` | Common Monitoring Footprint used for comparable annual monitoring from 2015–2025. |
| `feature_importance.png` | Relative importance of the Sentinel-1-derived predictors used by the ML models. |
| `threshold_analysis.png` | Model performance across probability-threshold analysis. |
| `temporal_analysis.png` | Annual 2015–2025 temporal monitoring results. |
| `temporal_outputs.png` | Example temporal monitoring outputs derived from the annual probability analysis. |
| `hotspot_evolution.png` | Spatial classification of persistent, emerging, and abandoned hotspot behaviour. |

## Source and use

The figures are adapted from the project's MSc thesis analysis and prepared
for GitHub rendering. They are provided as portfolio visuals and do not
replace the thesis as the full source document.

The figures should be interpreted together with the methodology, results,
notebooks, and scripts in this repository.
